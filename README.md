# NightAngel Portfolio

A minimal dark cyber-themed portfolio of NightAngel, built with HTML and CSS.

## Included

- `index.html`  — page structure and conten t
- `style.css`  custom responsive styling
- `angel-bg2.png`  angel/night visual used as a subtle background element

## Features

- Cyber / night visual direction
- Playfair Display for the requested editorial labels
- Doto for the main display name
- Larger terminal, buttons, journey link, toolkit and principle text for visibility
- CSS-only dark/light mode toggle (no JavaScript)
- No grid-pattern background
